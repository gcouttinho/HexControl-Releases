# HexControl downloads

Distribution repository for HexControl installers and update manifests. The application source is maintained separately.

Use the assets in the latest published release. Verify downloads with `SHA256SUMS.txt`.

Linux x64 is beta. macOS currently supports Apple Silicon; Intel downloads will appear after a validated native build. Current macOS builds use a persistent local signature, without Apple notarization. Windows commercial code signing is not configured.
